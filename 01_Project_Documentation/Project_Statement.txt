1. PROJECT TITLE

PortSwigger Web Security Academy – Apprentice-Level Web
Application Security Lab Assessment

============================================================

2. PROBLEM STATEMENT
============================================================

The objective of this project is to complete any five
Apprentice-level labs available on the PortSwigger Web
Security Academy.

For each selected laboratory, the vulnerability will be
identified, analyzed, and successfully demonstrated within
the authorized PortSwigger training environment.

The assessment will document the vulnerability, testing
methodology, exploitation process, technical evidence,
security impact, and appropriate defensive measures.

============================================================

3. PROJECT OBJECTIVE
============================================================

The primary objective is to develop practical web application
security testing skills through controlled and intentionally
vulnerable environments.

The project focuses on:

- Understanding common web application vulnerabilities.
- Using Burp Suite to intercept and analyze HTTP requests.
- Identifying vulnerable parameters and application behavior.
- Safely validating vulnerabilities in authorized labs.
- Understanding the security impact of vulnerabilities.
- Developing appropriate mitigation recommendations.
- Maintaining professional penetration-testing documentation.
