2. PRIMARY SECURITY TESTING TOOL
============================================================

Tool:
Burp Suite Community Edition

Purpose:

Burp Suite is used as the primary web application security
testing tool for:

- Intercepting HTTP requests and responses.
- Reviewing application traffic.
- Identifying parameters and inputs.
- Modifying requests.
- Replaying requests using Repeater.
- Analyzing server responses.
- Validating vulnerabilities.

============================================================

3. BURP SUITE COMPONENTS
============================================================

The following Burp Suite components may be used:

3.1 Proxy
------------------------------

Used to intercept and inspect HTTP/HTTPS traffic between the
browser and the authorized PortSwigger laboratory.

3.2 HTTP History
------------------------------

Used to review previously captured requests and responses.

3.3 Repeater
------------------------------

Used to manually modify and replay HTTP requests to validate
security behavior.

3.4 Target / Site Map
------------------------------

Used to understand the application's accessible endpoints and
identify relevant functionality.

============================================================

4. WEB BROWSER
============================================================

Browser:
Burp Browser / Chromium-based browser

Purpose:

- Accessing PortSwigger laboratory environments.
- Interacting with application functionality.
- Generating HTTP requests.
